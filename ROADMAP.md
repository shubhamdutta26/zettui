# Roadmap

Versions identify development milestones; not all have a separate published release tag.

## Completed

| Version | Features |
| --- | --- |
| 0.1.0 | File browser and UTF-8 previews |
| 0.2.0 | Vim-style editing, saving, protection from external changes |
| 0.3.0 | Create, rename, move, and Trash files/folders |
| 0.4.0 | Wiki links, Markdown links, backlinks, history |
| 0.5.0 | Search and insert Zotero JSON citations |
| 0.6.0 | Color themes, custom colors, filename finder |
| 0.6.1 | Automatic Omarchy light/dark theme selection |
| 0.7.0 | CI and Linux release packages |
| 0.7.1 | Documentation and repository cleanup |
| 0.7.2 | `[[` wiki-link autocomplete |
| 0.7.3 | Configurable and keyboard-resizable panes |
| 0.7.4 | Zettlr-style reusable note snippets |
| 0.7.5 | Full-vault text search, YAML tag search, Insert-mode blinking underline cursor |
| 0.7.6 | Theme addition, fixed editor cursor visibility, search within notes |
| 0.7.7 | Refined header, active-panel borders, directory and selection indicators, panel padding, cleaner footer, Midnight theme, configurable automatic light/dark presets |
| 0.7.8 | Mode indicators, word count, cursor position, breadcrumbs and redesigned pickers |
| 0.7.9 | Markdown highlighting, Zen, Focus, Typewriter, structured configuration and heading overrides |

## Release preparation

0.7.10: native Omarchy and terminal themes, contrast adjustment and repository maintenance. Direct COSMIC v2 integration is under testing.

## Planned

| Milestone | Possible work |
| --- | --- |
| 0.8.0 | Optional note metadata panel, configurable UI elements; refine existing sidebar resizing |
| 0.8.x | Search highlighting, ranked results, faster indexing, optional inline hashtag index |
| 0.9.x | Link-aware rename/move and broken-link reports |
| 0.10.x | Expanded Markdown and YAML syntax highlighting |
| Later | In-editor snippet tab stops, ARM64 packages, configurable ZKN IDs |

**Principles:** plain files, local-first, no silent overwrites, safe keyboard-driven workflows.
