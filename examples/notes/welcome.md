# Welcome to Zettui

This demonstration vault is safe to experiment with using a disposable copy.

- Browse with `j` and `k`; open a note with Enter.
- Press `i` to edit, Escape for Normal mode, and `:w` to save.
- Try `Space z` for Zen mode and `Space f` for focus.
- Search the vault with Ctrl+F.
